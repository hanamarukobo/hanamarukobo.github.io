この日に出るもの

行をタップすると、だれが・いつ・ごほうびなどを変えられます。使わなくなったものは「使う」を外すと、記録を残したまま出なくなります。

できるようになったこと（「もう できる」にまとめる）

言われなくてもできるようになったやることは、子どもごとの「もう できる」に1つにまとめられます。記録はずっと残ります。

この2週間よくできているものに「もう できるかも」と出ます。決めるのはおうちの人です。

みんなの目標

開始日からの全員のがんばりで進みます（ためたポイントは減りません）。ボードには、達成していない一番上の目標が出ます。

ごほうび交換

ごほうびの一覧

単位が「ポイント」のときに使います。残高は、ためたポイントから交換した分を引いたものです。

子ども

「表示」を外すと、記録は残したまま、ボードにもこのページにも出なくなります。ボードの設定（画面の左上の歯車 →「がんばりカレンダー」）と共通です。

カレンダー連携

どちらを選べばいい？

iCal の URL（おすすめ）：Google カレンダーなどの「iCal 形式の URL」を貼るだけで使えます。出し方は下の「Google カレンダーの URL の出し方」を見てください。

Apps Script：Google Apps Script で自分で用意した中継の URL です（予定の出し方を細かく変えたい人向け）。わからなければ iCal を選んでください。

Google カレンダーの URL の出し方
  1. パソコンのブラウザで Google カレンダーを開き、右上の歯車 →「設定」
  2. 左の「マイカレンダーの設定」から、子どもに見せたいカレンダーを選ぶ（家族用のカレンダーを1つ作っておくのがおすすめ）
  3. 「カレンダーの統合」の「iCal 形式の非公開 URL」をコピーして、上に貼り付ける
この URL を知っている人は誰でも予定を見られます。ほかの人に教えないでください。漏れたときは同じ画面の「リセット」で URL を作り直せます。URL はこの端末（またはこの家のサーバー）の中だけに保存し、外には送りません。

データの書き出し・読み込み

記録と設定を1つのファイルにします。機種変更の前に書き出しておくと、あとで戻せます（戻すと、いまの内容は置き換わります）。
