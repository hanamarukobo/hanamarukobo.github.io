Google の窓の試し

はなまるボードのブラウザ版で、Google ドライブに控えるときの「Google の画面」が、iPhone・iPad のホーム画面のアプリからでも戻ってくるかを試すページです。家族の記録は使いません。

いまの開き方

クライアント ID

Google Cloud で作った ID（…apps.googleusercontent.com）。このブラウザにだけ覚えます。ホーム画面のアプリは Safari と別なので、もう一度入れます（アドレスの最後に ?id=… を付けて開いても入ります）。

A: 窓（ポップアップ）で許可

アプリと同じ方式。押すと Google の画面が開き、許可すると ここに戻ります。

B: ページを移って戻る

A がだめだったときの代わりの方式。Google のページへ移り、許可すると このページに戻ります。Google Cloud のクライアントの「承認済みのリダイレクト URI」に を入れてあるときだけ使えます。

ドライブに書けるか

A か B で許可が取れたあとに押します。「はなまるボードの試し.txt」を作り、読み直してから消します（ドライブには残りません）。

結果を送る

下の記録をコピーして送ってください（許可の中身（トークン）は記録に入れていません）。

試す順番

  1. Safari のタブのまま A → ドライブに書けるか
  2. 共有 → 「ホーム画面に追加」→ ホーム画面のアイコンから開く → ID を入れる → A → ドライブに書けるか
  3. A がだめなら、ホーム画面のアプリで B → ドライブに書けるか
  4. 記録をコピーして送る
