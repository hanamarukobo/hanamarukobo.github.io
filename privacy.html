プライバシーポリシー

制定日: 2026年11月2日　最終更新: 2026年11月26日

「はなまるボード」（以下「本アプリ」）は、家庭のリビングなどに置いたタブレットで、子どもの毎日のやること・天気・予定を表示するアプリです。本アプリが扱う情報と、その扱い方を説明します。

本アプリの運営者は、利用者や子どもの情報を集めません。記録や設定は、本アプリを入れた端末の中だけに保存します。広告は表示しません。このサイトとブラウザ版では、開かれた数だけを、個人を特定しない形で数えています（3. の最後）。

1. 本アプリが扱う情報

本アプリの中で、利用者（保護者）が入力した次の情報を扱います。

  • 子どもの呼び名（ニックネームで構いません）、表示の色、年齢の目安（ようちえん・ほいくえん／小学1〜2年／小学3年〜）
  • やることの内容とポイント、毎日の記録（できたこと・回数・保護者の確認）
  • 子どもごとのもくひょう（ポイントの目安）と、「こうかんした」の記録
  • おさいふの記録（ほしいもの、使ったお金・入れたお金・ちょきんの記録。「おさいふ」を使う子どもだけ）
  • 表示の設定（天気の地域、予定の読み込み先（カレンダーの URL か、選んだ端末のカレンダー）、表示する時間帯、保護者用の画面の鍵 など）

このほか、画面に表示するためだけに、端末の電池の状態（残量・温度など）を読み取ります。保存や送信はしません。

Android のアプリで予定の読み込み先に「この端末の Google カレンダー」を選んだときは、カレンダーを読む許可（READ_CALENDAR）をもらって、端末に入っているカレンダーから選んだものの予定を読み取り、画面に出します。端末の中には選んだカレンダーの印だけを保存し、予定は外部に送りません（2台連携でつないだスマホには、家の Wi-Fi の中だけで渡します）。カレンダーに書き込むことはありません。

本アプリは、氏名・住所・電話番号・メールアドレス・写真・端末の位置情報（GPS など）・端末の識別子・広告 ID を集めません。Android のアプリには、広告や利用状況の分析のための仕組み（広告 SDK・解析 SDK）は入っていません。

2. 保存する場所

上の情報は、本アプリを入れた端末の中だけに保存します。運営者のサーバーには送りません。

  • 保護者が「データの書き出し」を使うと、端末の「ダウンロード」フォルダに JSON ファイルを保存します。このファイルの扱い（保存・共有・削除）は利用者の管理になります。
  • 「置いて、別の端末からつなぐ」（2台連携）にすると、置いた端末が同じ Wi-Fi の中にだけ自分の存在を知らせ、つなぐための番号（6けた）を入れたスマホのアプリ、または置いた端末に出る QR コード（番号を含みます）を読み取ったブラウザからの読み書きだけを受け付けます。データは置いた端末の中にあり、家の Wi-Fi の外には送りません。番号は設定から変えられ、変えると前の番号ではつながらなくなります。
  • ブラウザ版（iPad などのブラウザで開くもの）では、上の情報をその端末のブラウザの中に保存します。ページを配るサーバーには送りません。
  • ブラウザ版で、保護者が設定の「おうちの人」の「Google ドライブに控える」を使うと、上の情報を、端末（ブラウザ）ごとに1つのファイル（はなまるボードの控え.json）にして、保護者の Google ドライブに保存します。ほかの端末の控えを上書きすることはありません。どの控えを使うかを一覧で選べるように、ファイルには目印として、端末の種類（「iPad・Safari」など。ブラウザの名前から作ります）・子どもの名前と人数・記録の日数といちばん古い日を付けます（目印も保護者のドライブにだけ置きます）。控えは保護者のドライブにあり、運営者のサーバーには送りません（運営者は見られません）。本アプリが触れるのは、本アプリが作ったファイルだけです（Google ドライブの drive.file の範囲）。はじめに「Google ドライブとつないではじめる」を選んだときや、設定の「おうちの人」で控えたときから「つないでいる」状態になり、その間は記録が変わるたびに自動で控えます。そのために、つないでいる間は、起動したとき・設定を開いたとき・記録が変わったとき・ボタンを押したときに、Google（accounts.google.com・www.googleapis.com）に通信します。Google の許可（通行証）は端末のメモリにだけ置き、保存しません。つなぐのをやめるときは、設定の「おうちの人」の「つなぐのをやめる」を押すか、Google アカウントの設定（サードパーティ製のアプリとサービス）から、いつでも外せます。つないだ Google アカウントのメールアドレスは、つなぎ直すときにアカウントを選ばなくて済むように、この端末（ブラウザ）の中だけに覚えます（運営者には送りません。つなぐのをやめると消します）。名前は受け取りません。Google から受け取る情報は控えの保存と読み戻しのためだけに使い、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。Android のアプリにはこの機能はありません。
  • Android の自動バックアップ（Google ドライブ）が有効な端末では、Android の仕組みにより本アプリのデータがバックアップされることがあります。バックアップは利用者の Google アカウントに保存され、運営者は見られません。

3. 外部に送る情報

表示のために、次の外部サービスへ通信します。いずれも、子どもや家族に関する情報や、利用者を特定できる情報は送りません。

送り先目的送る内容
気象庁（www.jma.go.jp）天気予報・雨の予報の取得選んだ地域のコード（例: 130010）、市区町村の役所あたりを含む地図の区画（約30km四方の画像の番号）
国土地理院（msearch.gsi.go.jp）選んだ市区町村の位置（緯度・経度）を調べる。結果は端末の中に保存し、市区町村を変えたときだけ調べ直す都道府県名と市区町村名（例: 東京都練馬区）。住所の番地や端末の位置情報は送らない
利用者が設定したカレンダーの URL（Google カレンダーなど）予定の取得URL への読み込みの要求のみ

祝日は端末の中で計算し、外部には問い合わせません。

「1回だけのやること」を声で入れるときは、端末に入っている音声認識の機能（Google の音声入力など）を呼び出します。声の扱いはその機能の提供元のポリシーに従います。本アプリが受け取るのは認識された文字だけで、声は保存しません。

設定の「ヘルプ」の「ご要望・お問い合わせ」は、保護者のスマホで読み取る QR コードを表示するだけです。読み取って開く受付フォーム（Google フォーム）に送った内容（本アプリのバージョンと機種が最初から入っています）は、運営者が要望・問い合わせへの対応のためだけに使います。本アプリから直接は送りません。

通信の際、通常のインターネット通信と同じく、送り先に端末の IP アドレスなどが伝わります。各サービスでの扱いは、それぞれのプライバシーポリシーに従います。

カレンダーの URL（Google カレンダーの「iCal 形式の非公開 URL」など）は、それを知る人が予定を見られる情報です。本アプリは URL を端末の中にだけ保存し、外部に送りません（読み込みのためにその URL へ通信するだけです）。

アクセスの数: このサイト（hanamarukobo.github.io）とブラウザ版では、どんな端末やブラウザで開かれているかを知り、今後の対応（iPhone・iPad 向けなど）を決めるために、GoatCounter（www.goatcounter.com）で開かれた数を数えています。送るのは、開いたページのアドレス、どのページから来たか、ブラウザと OS の種類、画面の幅、言語です（つなぐための番号が入ったアドレスで開いたときは、何も送りません）。ブラウザ版では、使っている端末の数を知るため、その端末ではじめて開いたとき・その日はじめて開いたとき・7日使ったときに、そのことを表す印と端末の種類（iPhone・iPad・Android・PC）も送ります。印を送ったかどうかは、端末の中に覚えます。GoatCounter は IP アドレスから国を推定しますが、IP アドレスは保存せず、cookie などで端末に印を残すこともしません。子どもや家族の記録は送りません。Android のアプリでは数えません。GoatCounter での扱いは、GoatCounter のプライバシーポリシー（https://www.goatcounter.com/help/privacy）に従います。

4. 子どもの情報について

本アプリは子どもと一緒に使うことを想定しています。子どもについての情報は保護者が入力し、端末の外には送りません。子どもが本アプリから外部のサイトを開いたり、買い物をしたりすることはできません。保護者用の画面（設定・「みました」）には、保護者が鍵（計算問題または4桁の番号）をかけられます。

5. 情報の削除

  • 子どもは設定の「子ども」で表示を外せます。やることは設定の「やること」で直したり、使わないようにしたりできます。
  • すべてのデータを消すには、端末の設定で本アプリのデータ（ストレージ）を消去するか、本アプリをアンインストールしてください。運営者はデータを持っていないため、運営者の側で消す操作はありません。
  • ブラウザ版の記録は、ブラウザの設定でこのサイト（hanamarukobo.github.io）のデータを消すと消えます。
  • ブラウザ版で Google ドライブに控えたファイルは、保護者の Google ドライブから削除してください。
  • 書き出したファイルは、端末の「ダウンロード」フォルダなどから利用者が削除してください。

6. このポリシーの変更

機能の追加（家族の端末どうしの同期など）で扱う情報が変わるときは、このポリシーを更新し、アプリ内または掲載ページでお知らせします。
